Privacy Policy

Last updated: 2026-10-27

Fitbit Air MCP is a personal tool used only by its owner. It requests read-only access to Google Health sleep, activity and fitness, and health metrics data.

  • Data is read on the owner's own computer and passed only to the owner's own Claude app when the owner asks a question.
  • No data is uploaded to, stored on, or shared with any server operated by this tool or with any third party.
  • The OAuth refresh token is stored in the macOS Keychain on the owner's computer.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

隐私政策（中文）

本工具仅供所有者本人使用，只读访问 Google Health 的睡眠、活动与健身、健康指标数据。数据只在本机读取，仅在本人提问时交给本人的 Claude 应用；不上传、不存储到任何服务器，也不与任何第三方分享。授权令牌保存在本机的 macOS 钥匙串中，可随时在 Google 账号的「第三方应用访问权限」中撤销。
